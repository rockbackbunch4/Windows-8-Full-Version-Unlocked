## Main Features
<a id="main-features"></a>

### Core Functionality
- **Modern UI Tactile Interface** — Windows 8 introduced a visually appealing interface designed for touchscreens, making navigation intuitive on tablets and touchscreen laptops.
- **Tile Organization** — Applications are organized using tiles on the Start Screen, allowing users to easily access their favorite programs and websites.
- **Full-Screen Applications** — Most applications run in full-screen mode, providing an immersive experience without traditional toolbars.
- **Charms Bar Functionality** — The classic Start Menu was replaced by the Charms Bar, streamlining access to essential functions like search, share, and settings.
- **ARM and x86 Support** — Windows 8 supports both ARM microprocessors and traditional x86 processors, enhancing compatibility across devices.

### Advanced Capabilities
- **Customizable Lock Screen** — Users can customize the Lock Screen to display notifications, adding personalization to their device's security features.
- **Internet Explorer 10** — A new version of Internet Explorer optimized for touch interactions, enhancing web browsing on touch-enabled devices.
- **Integrated Skype** — Built-in Skype functionality allows instant messaging and video calling directly from the operating system.
- **Multitasking Support** — Users can run multiple applications simultaneously, utilizing the screen space effectively to boost productivity.
